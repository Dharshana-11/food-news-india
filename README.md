# Food News India (MVP)

## Overview
Mobile-first app for small food businesses to manage compliance & documents.

## Local Setup (basic)
1. Clone:
   `git clone https://github.com/your-username/foodnewsindia.git`
2. Install root/clients/servers:
   - `cd client && npm install`
   - `cd ../server && npm install`
3. Create `.env` files based on `.env.example`.
4. Start dev:
   - run client: `npm start` (in client/)
   - run server: `npm run dev` (in server/)
